# Mini CTF Challenges 2026

This repository contains the challenges and infrastructure developed for a Mini Capture The Flag (CTF) event organized as a training activity for the Cybersecurity Cell of Apps Club.

## About the Event

The Mini CTF was designed to introduce participants to different cybersecurity domains through practical, hands-on challenges. The goal was to help students develop problem-solving skills and gain experience with common CTF categories.

## Challenge Categories

- Web Security
- Cryptography
- Reverse Engineering
- Digital Forensics
- Steganography
- Binary Exploitation (Pwn)
- Miscellaneous

## Technologies Used

- Docker
- Python
- Shell Scripts
- HTML/CSS

These challenges were created for educational and training purposes only. Participants were encouraged to learn, experiment, and develop their cybersecurity skills in a controlled environment.
